# 流量雷达（X 中文圈）

当一条内容在 **X 的中文圈**具备传播潜力时使用此配置。X 的中文用户高度集中在三个圈层，只收这三类：

1. **科技 / AI**：模型与产品发布、开发者工具的坑与事故、大厂动向、开源争议、芯片与算力
2. **财经 / 加密**：市场异动、监管与罚单、公司与人物翻车、币圈事件、普通人钱袋子的变化
3. **国际政治时评**：大国博弈、政客言行、监管与科技公司的冲突、能引发立场对撞的事件

判断标准不是"重要"，而是**中文 X 用户会不会转发、会不会在引用里吵起来**。

不包括：体育赛事、国内娱乐八卦、明星行程、生活方式内容、纯商业通稿、无具体人物与数字的行业分析、需要专业背景才懂的深度技术文章。

**明确排除社会案件与民生纠纷**：凶杀、庭审细节、交通事故、邻里冲突、消费者与店员争执——这类内容在微博有流量，在 X 的中文圈没有，而且道德风险高。

**安全边界**：不涉及中国国内政治敏感议题、不对具体个人做未经证实的指控、不传播匿名爆料。这三条会连带账号一起死。
