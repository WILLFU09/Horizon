# 评估目标

评估一条信息在**中文 X 圈**的传播潜力，范围限定在科技地缘政治与国际时政。这是注意力评分，不是价值评分。

# 评分标准

- **9–10：圈层爆款。** 有清晰的对抗双方、有具体动作（禁令、断供、打击、判决）、有可见代价，中文 X 会连续几天讨论。
- **7–8：值得写。** 有具体新事实和明确博弈关系，能形成一个有立场的判断。
- **5–6：可作素材。** 信息成立但缺细节，或只是表态没有后果。
- **3–4：低优先级。** 例行外交辞令、重复报道、只有情绪没有新事实。
- **0–2：噪音。** 无法核实的传闻、匿名爆料、与科技或国际格局无关。

# 传播潜力加分项

- **对抗性**：国家 vs 国家、公司 vs 政府、盟友 vs 盟友，有明确的双方
- **代价转移**：谁被牺牲——消费者、开发者、小国、供应链下游
- **反常识**：制裁没生效、禁令反噬自己、联盟出现裂缝、巨头公开叫板
- **数字冲击**：金额、关税、份额、产能、用户数
- **时间差**：24 小时内刚发生，中文圈尚未写透

# 传播潜力减分项

- 只有表态、没有具体动作或后果
- 需要专业背景才能理解的技术细节
- 已被大量账号写烂且无新增事实

# 硬性降级（不受话题热度影响）

- **中国国内政治与政策**：最高 3 分。不在本账号定位内，且风险不可控。
- **社会案件与民生纠纷**：最高 3 分。
- **体育赛事、娱乐八卦**：最高 3 分。

# 评估要求

区分已发生的事实与传闻。**硬约束：凡主要事实来自单一来源、匿名爆料、或需标注"传闻/消息称/待核实"的内容，评分不得超过 5 分。** 涉及具体个人的负面指控必须标明来源；来源不可靠直接判 0–2 分。
