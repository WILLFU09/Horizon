# 评估目标

评估一条信息在未来 24 小时内能带来多少**大众注意力**。这是传播潜力评分，不是价值评分：一条重要的行业分析可能打 3 分，一条荒诞的社会新闻可能打 9 分。

# 评分标准

- **9–10：全民话题。** 任何年龄段、任何职业都能说两句；有清晰的对立面或强烈的情绪；媒体会连续跟进多天。
- **7–8：垂类爆款。** 有明确受众群（游戏、股民、宝妈、程序员等），群体内会大量转发并争论。
- **5–6：可做素材。** 有记忆点，但传播半径有限，或需要与其他素材拼成合集。
- **3–4：小众。** 只有行业内的人关心，普通人看了没有反应。
- **0–2：无传播力。** 通稿、术语堆砌、无具体人物与数字、纯商业公告。

# 传播潜力加分项

- **情绪**：愤怒、恐惧、荒诞、羡慕、后怕——只要读者会产生明确情绪
- **身份**：涉及"我们这类人"（打工人、家长、程序员、股民、年轻人）
- **数字冲击**：金额、人数、价格、倍数足够大或足够反常
- **反差**：身份与行为的错位、官方说法与事实的差距
- **可站队**：读者能立刻选一边，并在评论区表达

# 传播潜力减分项

- 需要背景知识才能理解
- 没有具体人物、地点、数字
- 纯商业公告或融资新闻
- 已经被全网写烂且无新角度

# 硬性降级（不受话题热度影响）

- **社会案件**：凶杀、碎尸、庭审细节、事故伤亡、失踪——最高 3 分。这类内容在 X 中文圈没有受众，且道德风险极高。
- **民生纠纷**：消费者与店员争执、邻里冲突、让座与插队——最高 3 分。
- **体育赛事、国内娱乐八卦、明星行程**：最高 3 分。

# 评估要求

区分已发生的事实与传闻。**硬约束：凡主要事实来自单一来源、匿名爆料、或需要标注"传闻/消息称/待核实"的内容，评分不得超过 5 分，不受话题热度影响。** 涉及具体个人的负面指控，必须标明信息来源；来源不可靠时直接判 0–2 分并写明原因。
